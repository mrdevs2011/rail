Navigatsiya va Fokus

Klavish Vazifasi Tavsif
Alt + H Chap ustunga o'tish Chap tomondagi ustunga fokusni o'tkazadi (xuddi shu balandlikdagi oynaga)
Alt + L O'ng ustunga o'tish O'ng tomondagi ustunga fokusni o'tkazadi (xuddi shu balandlikdagi oynaga)
Alt + J Pastdagi oynaga o'tish Ustun ichida pastdagi oynaga; ustun oxirida — pastdagi ish maydoniga (workspace)
Alt + K Yuqoridagi oynaga o'tish Ustun ichida yuqoridagi oynaga; ustun boshida — yuqoridagi ish maydoniga
Alt + [ Chap ustunga yig'ish / ajratish niri'dagidek: yolg'iz oyna chap ustunga stack bo'ladi; stack ichidagi oyna chapga alohida ustun bo'lib chiqadi
Alt + ] O'ng ustunga yig'ish / ajratish Yolg'iz oyna o'ng ustunga stack bo'ladi; stack ichidagi oyna o'ngga alohida ustun bo'lib chiqadi
Alt + Shift + H Ustunni chapga ko'chirish Butun ustunni (stackdagi barcha oynalar bilan) chapga suradi
Alt + Shift + L Ustunni o'ngga ko'chirish Butun ustunni (stackdagi barcha oynalar bilan) o'ngga suradi
Alt + Shift + J Oynani pastga surish Stack ichida pastdagi oyna bilan almashadi; stack bo'lmasa — pastdagi ish maydoniga o'tkazadi
Alt + Shift + K Oynani yuqoriga surish Stack ichida yuqoridagi oyna bilan almashadi; stack bo'lmasa — yuqoridagi ish maydoniga o'tkazadi
Ctrl + Tab Keyingi tab Joriy qatordagi keyingi oynaga aylanma o'tadi (Ctrl+Shift+Tab — oldingisiga)
Ctrl + 1…9 N-tabga o'tish Joriy qatordagi 1–9-oynaga o'tadi (Ctrl+9 — oxirgisi)
Alt + 1…9 N-ish maydoniga o'tish 1–9-ish maydoniga (qatorga) o'tadi; Alt+Shift+1…9 oynani shu yerga ko'chiradi

Oynalar va Lenta Boshqaruvi

Klavish Vazifasi Tavsif
Ctrl + T Yangi tab / Omnibar Omnibar'ni ochadi va yangi tab yaratadi (yangi tab fokusdagi ustunning o'ng tomonida ochiladi)
Ctrl + L URL qatori (Omnibar) Joriy tab uchun manzil/qidiruv qatorini ochadi
Alt + Shift + V Yangi ish maydoni Joriy qatordan pastda yangi ish maydoni (workspace) ochadi
Ctrl + W Tabni yopish Fokusdagi veb-oynani yopadi
Ctrl + R Qayta yuklash Fokusdagi veb sahifani qayta yuklaydi
Alt + F To'liq kenglik / Split Ustunni to'liq ekran kengligiga yoyadi yoki 50% rejimiga qaytaradi

Ko'rinish va Rejimlar

Klavish Vazifasi Tavsif
Alt + O Fazoviy Overview Lentani kichraytirib, barcha qatorlar, ustunlar va stacklarni haqiqiy joylashuvida ko'rsatadi. h/j/k/l — harakat, Enter — ochish, x — yopish, Esc — bekor qilish
Alt + B Yon panel (Sidebar) Yon panelni ochish yoki yashirish
Alt + M Roadmap / Minimap Tablar xaritasini ochadi yoki yopadi
Alt + P Profillar dialogi saqlash izolyatsiyasiga ega profillar ro'yxatini ochish va tezkor almashtirish
Alt + I Data & Backup Ma'lumotlar zaxirasi va ko'chirish oynasini ochadi
Alt + S Sozlamalar Sozlamalar panelini ochadi yoki yopadi
Alt + Shift + T Touchpad kanvas Sensorli panel orqali kanvas navigatsiyasini yoqadi/o'chiradi
F12 DevTools Dasturchi vositalarini ochadi yoki yopadi (Alt+Shift+D — joylashuvini almashtirish)
F11 To'liq ekran To'liq ekran rejimini almashtiradi
Alt + Left Orqaga Joriy tab tarixida orqaga o'tadi
Alt + Right Oldinga Joriy tab tarixida oldinga o'tadi
Ctrl + Q Chiqish Rail'ni yopadi
