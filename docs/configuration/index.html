Konfiguratsiya va Sozlamalar

Rail soddalik va moslashuvchanlik tamoyiliga tayanadi. Barcha sozlamalar JSON formatida saqlanadi.

Sozlamalar Fayli Joylashuvi

Konfiguratsiya ~/.config/rail/config.json manzilida saqlanadi. Uni istalgan matn muharririda ochib o'zgartirishingiz mumkin:

~/.config/rail/config.json 
{
  "language": "uz",
  "search_engine": "https://duckduckgo.com/?q=%s",
  "default_profile": "default",
  "ui": {
    "theme": "black_white_blue",
    "column_min_width": 480,
    "overview_zoom": 0.65,
    "animations": true
  },
  "privacy": {
    "do_not_track": true,
    "clear_cache_on_exit": false
  }
}

Interfeys Tili (i18n)

Rail to'liq 3 ta tilni qo'llab-quvvatlaydi: O'zbekcha (sukut bo'yicha), Inglizcha va Ruscha. Tilni Settings menyusidan yoki rail --lang <uz|en|ru> orqali o'zgartirish mumkin.

Maxsus CSS Usullar

Saytlarning ko'rinishini o'zingizga moslashtirish uchun foydalanuvchi CSS qoidalari ~/.config/rail/custom.css faylida kiritilishi mumkin.

~/.config/rail/custom.css 
/* Tungi rejimni majburiy qilish */
html {
  filter: contrast(102%) brightness(98%);
}

/* Scrollbar dizaynini ixchamlashtirish */
::-webkit-scrollbar {
  width: 5px;
  height: 5px;
}
::-webkit-scrollbar-thumb {
  background: #2f6bff;
}
