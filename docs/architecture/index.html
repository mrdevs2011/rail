Arxitektura va Ichki Tuzilish

Rail noldan GTK4, WebKitGTK 6.0 va Rust dasturlash tilida qurilgan bo'lib, uning binar hajmi atigi ~500 KB ni tashkil qiladi.

Texnologik Stek

Boshqa ko'plab zamonaviy brauzerlardan (masalan Electron asosidagi) farqli ravishda, Rail xotira va protsessordan minimal foydalanadi:

Qatlam Kutubxona / Crate Vazifasi & Xususiyatlari
Asosiy til Rust 2021 / 2024 Xotira xavfsizligi (memory-safety), nol abstraksiya narxi, yuqori tezlik
Grafik interfeys GTK4 (gtk4 crate) GSK (GTK Scene Graph), apparatli tezlashtirish (GPU rendering), Wayland va X11 native integratsiyasi
Veb dvigatel WebKitGTK 6.0 Zamonaviy HTML5, CSS3, ECMAScript, izolyatsiyalangan WebKitNetworkSession instansiyalari
2D Lenta tizimi strip.rs (StripLayout) Niri kompozitori koordinata modeli, dinamik masshtablash, 2D staklar
Serializatsiya minijson.rs Hech qanday tashqi bog'liqliksiz (zero-dependency) tezkor JSON saqlagich

2D StripLayout mexanizmi (`strip.rs`)

Rail brauzerida oynalarning joylashishi maxsus GTK Layout Manager — StripLayout orqali boshqariladi. Bu niri Wayland kompozitorining koordinata hisoblash algoritmidan ilhomlangan:

src/strip.rs — StripLayout koordinata hisoblash yadrosi 
pub const GAP: f64 = 6.0;
pub const MIN_COL_W: f64 = 480.0;

/// Oraliq masofa (gap) zoom pasayganda kattalashadi, 
/// bu orqali Overview rejimida ustunlar bir-biriga yopishib ketmaydi:
pub fn gap(zoom: f64) -> f64 {
    GAP + (1.0 - zoom) * 40.0
}

/// Ustun kengligini hisoblash: to'liq ekran yoki yarim viewport
pub fn col_width(full: bool, viewport: f64) -> f64 {
    if full || viewport < (MIN_COL_W * 2.0 + GAP) {
        viewport.max(280.0)
    } else {
        ((viewport - GAP) / 2.0).floor()
    }
}
Eslatma: 2D Grid Matritsasi

Har bir oynaning holati xotirada Vec<Vec<bool>> ko'rinishidagi 2D matritsada saqlanadi. Gorizontal indeks ustunni (Column), vertikal indeks esa ustun ichidagi stak oynasini (Row) bildiradi.

Profillar izolyatsiyasi (`profile.rs`)

Har bir profil o'zining mustaqil WebKitNetworkSession instansiyasiga ega bo'lib, uning fayllari ~/.local/share/rail/profiles/{id} papkasida saqlanadi. Kesh, kuki va WebStorage xotiralari tizim darajasida to'liq ajratilgan.

src/profile.rs — WebKitNetworkSession yaratish 
pub fn create_session(data_dir: &PathBuf) -> NetworkSession {
    let cache_dir = data_dir.join("cache");
    let data_dir_str = data_dir.to_string_lossy();
    let cache_dir_str = cache_dir.to_string_lossy();

    // Har bir profil uchun alohida kuki va kesh saqlash joyi:
    NetworkSession::new(Some(&data_dir_str), Some(&cache_dir_str))
}
