# Rail

**Rail** — a web browser that scrolls sideways (built with GTK4 and WebKitGTK).

## Quick Install (Linux)

To install Rail via a single command:

```bash
curl -fsSL https://raw.githubusercontent.com/mrdevs2011/rail/main/install.sh | bash
```

Run with:
```bash
rail
```

## Features
- **Sideways / Horizontal scrolling**: tabs appear as columns that pan horizontally.
- **GTK4 & WebKitGTK**: native Wayland/Linux performance.
- **Standalone AppImage**: bundles necessary GTK4 and WebKit libraries.
