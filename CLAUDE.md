# Rail Browser

Rust brauzer (Linux, `rail-linux-x86_64`), sync va PWA qo'llab-quvvatlaydi.

Batafsil: `README.md`, `STATUS.md`, `RELIABILITY.md`, `docs/`.

## Komandalar
- `cargo build --release` — build (uzoq vaqt oladi, faqat kerak bo'lganda)
- `cargo check` — tez tekshiruv

## Qoidalar
- Foydalanuvchiga **o'zbek tilida** javob ber.
- Faqat so'ralgan vazifani qil. Keraksiz refaktor qilma.
- `target/` papkasini hech qachon o'qima va commit qilma.
- Commit va `main` ga push faqat men so'raganda. Push oldidan `cargo check` o'tishi shart.
- Brauzer umumiy standartlar bo'yicha qurilsin; MYplan yoki boshqa saytga maxsus bog'lanma.
- Light mode'da foydalanuvchi hech qachon qora fon ko'rmasin.

## Maxfiylik
- Kalit va tokenlarni chatga yozma, commit qilma.
